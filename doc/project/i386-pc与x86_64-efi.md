| 目录 | GRUB 平台 | 给谁用 | 最终产物 |
| --- | --- | --- | --- |
| `arch/amd64/grub2/i386-pc/` | Legacy BIOS（16 位实模式） | 老 BIOS / CSM | 写入 MBR 前 440 字节的 `boot.img` + 1MiB 空隙里的 `core.img` |
| `arch/amd64/grub2/x86_64-efi/` | 64 位 UEFI | 现代 UEFI 固件 | `grub-mkimage -O x86_64-efi` 生成 `EFI/BOOT/BOOTX64.EFI` |

`x86_64-efi` 才是 **UEFI/EFI 构建**用的。`i386-pc` **不参与 EFI**，只服务 Legacy BIOS。

里面的 `.mod` 是 GRUB 自己的文件系统、分区、磁盘、菜单模块（`part_msdos`、`fat`、`ext2`、`linux`…），**不是**主板厂商 EFI 驱动，也**不是**内核驱动。

这是 Alpine 官方的 **GRUB2 通用二进制**（当前是 2.14），按 **CPU 指令集 + 固件规范** 分类，同一套模块可以给 Intel / AMD、虚拟机、多数国产 x86（海光、兆芯、部分 Intel 国产整机）用，**前提是固件遵守 BIOS 或 UEFI 规范**。

GNU 不单独提供「下载一个 zip 就得到全套 .mod」的官方二进制树。官方发布的是源码包，自己（或发行版）./configure && make 后，才会在构建目录里出现 i386-pc/、x86_64-efi/。

| | `.mod` | `.module` |
| --- | --- | --- |
| 格式 | ELF relocatable（未 strip） | ELF relocatable（已 strip） |
| 体积 | 约 11KB（acpi） | 约 7KB（acpi） |
| 数量 | 与 `.module` 几乎一一对应 | 一一对应 |
| 谁用 | `insmod`、`grub-mkimage`、`grub-install` | 构建阶段用，启动不用 |

GNU GRUB 构建过程大致是：
```
*.c  --编译-->  *.o  --链接-->  *.module  --objcopy/打包-->  *.mod
```
