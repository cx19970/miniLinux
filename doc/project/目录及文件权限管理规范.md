| 类别 | 判定 | mode |
|------|------|------|
| 目录 | `-d` | `0755` |
| 符号链接 | `-L` | 跳过 |
| ELF（可执行 / PIE / 动态库 / grub `.mod`） | `\x7fELF` | `0755` |
| 脚本 | 前两字节 `#!` | `0755` |
| 脚本（无 shebang） | `.sh` `.bash` `.ksh` `.zsh` `.dash` `.csh` `.tcsh` `.py` | `0755` |
| grub 模块名兜底 | `.mod` | `0755` |
| 压缩内核名兜底 | `bzImage` `vmlinuz*` `vmlinux` `zImage` `Image` | `0755` |
| 其余 | 文本、配置、`.lst`、`.cfg` 等 | `0644` |
