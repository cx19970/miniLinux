## 一、Legacy 模式规范

### 1、分区规范 MBR

| 项目 | 规范细节 |
| --- | --- |
| 分区表类型 | 必须使用 **MBR（Master Boot Record）** |
| 物理结构 | 磁盘第 0 扇区（LBA 0）共 512 字节：446 字节引导代码 + 64 字节分区表 + 2 字节校验签名（`0x55AA`） |
| 分区数量 | 最多 **4 个主分区**；或 3 个主分区 + 1 个扩展分区（扩展分区内可划分多个逻辑分区） |
| 容量限制 | 单磁盘最大 **2 TB**，单分区最大 2 TB（32 位 LBA 寻址） |
| 引导规则 | 必须标记 1 个主分区为**活动分区（Active）**，BIOS 仅加载活动分区的引导扇区 |
| 强制分区 | 无任何强制分区，引导代码可直接写入 MBR，系统可仅用 1 个根分区 |

### 2、文件系统规范

| 分区 | 文件系统要求 | 说明 |
| --- | --- | --- |
| 引导分区（/boot 或根分区） | 无强制格式，由引导程序决定支持范围 | 兼容性最优：**ext2**（GRUB Legacy / GRUB2 / Syslinux / 全版本内核均原生支持）常见可选：FAT16/32、ext3注意：GRUB Legacy（0.9x）**不支持 ext4** |
| 根分区 | 无限制，内核支持即可 | 可使用 ext2/3/4、xfs、btrfs 等任意格式 |
| ESP 分区 | 不存在 | Legacy 模式无 ESP 分区概念，无 FAT32 强制要求 |

## 二、UEFI 模式规范

### 1、分区规范 GPT

| 项目 | 规范细节 |
| --- | --- |
| 分区表类型 | 纯 UEFI 模式**建议使用 GPT**；CSM 兼容模式本质是退化为 Legacy 引导。UEFI 规范要求固件同时支持 GPT 和 MBR。MBR 上类型为 0xEF 的分区就是 ESP，这是规范里的合法 UEFI 引导方式，不是 CSM，也不是 Legacy。Windows 自己要求 UEFI 必须 GPT，那是微软限制，不是 UEFI 规范 |
| 物理结构 | LBA 0：保护性 MBR（防旧工具误删）LBA 1：GPT 头部LBA 2~33：分区表磁盘末尾：GPT 头部 + 分区表备份 |
| 分区数量 | 标准最多 **128 个分区**，无扩展分区概念。GPT 没有主分区/扩展分区之分，不能叫「主分区」 |
| 容量限制 | 单磁盘最大 **9.4 ZB**（64 位 LBA 寻址） |
| 强制分区 | 必须至少有 1 个 **ESP（EFI 系统分区）**，分区类型 GUID 为 `C12A7328-F81F-11D2-BA4B-00A0C93EC93B` |
| 可选特殊分区 | BIOS boot 分区（GPT 盘走 Legacy 启动时用）、MSR 分区（Windows 专用，Linux 不需要） |

### 2、文件系统规范

| 分区 | 文件系统要求 | 说明 |
| --- | --- | --- |
| **ESP 分区** | **支持 FAT12/FAT16/FAT32 格式** | UEFI 规范 2.5+ 硬性要求，固件原生仅识别 FAT12/FAT16/FAT32，Linux 挂载点通常为 `/boot/efi`推荐大小：32~100 MB（超小系统可低至 32 MB）作用：存放 `.efi` 格式引导程序、UEFI 驱动。合法 FAT32 在 512 字节扇区上大约需要 33–36 MiB，32 MB 经常格式化失败或变成无效 FAT32。超小 ESP 更合理的是 FAT16，而不是硬做成 FAT32 |
| /boot 分区（可选） | 无强制格式，由引导程序决定 | 全兼容最优：**ext2**（全版本 GRUB2、u-boot 均支持，兼容 2.x~7.x 内核）现代常用：ext4关键：ESP 分区 ≠ /boot 分区，二者功能完全独立 |
| 根分区 | 无限制，内核支持即可 | 可使用 ext2/3/4、xfs、btrfs 等任意格式 |

## 三、Legacy + UEFI 双兼容分区方案

| 分区 | 类型 | 文件系统 | 推荐大小 | 作用 |
| --- | --- | --- | --- | --- |
| BIOS boot 分区 | BIOS boot 类型 | 无文件系统（裸数据） | 1 MB | Legacy BIOS 下 GRUB2 存放 stage2 引导代码 |
| ESP 分区 | EFI System 类型 | FAT32 | 32 MB | UEFI 模式下存放 .efi 引导程序 |
| /boot 分区 | Linux 类型 | ext2 | 16~32 MB | 存放内核、initramfs、引导配置，两种模式通用 |
| 根分区 | Linux 类型 | ext2 | 剩余空间 | 系统根文件系统，全版本内核兼容 |

## 四、Legacy 与 UEFI 核心规范差异

| 维度 | Legacy BIOS 模式 | UEFI 模式 |
| --- | --- | --- |
| 对应分区表 | MBR | GPT |
| 最大主分区数 | 4 个 | 128 个 |
| 最大磁盘容量 | 2 TB | 9.4 ZB |
| 强制分区 | 无（需标记活动分区） | ESP 分区（必须） |
| 引导代码位置 | MBR 扇区 + 分区引导扇区 | ESP 分区内的 `.efi` 可执行文件 |
| ESP 分区 | 不存在 | 必须，且必须为 FAT32 |
| /boot 最优格式 | ext2（全兼容） | ext2（全兼容）/ext4（现代） |
| 根文件系统限制 | 无 | 无 |
| Secure Boot 支持 | 不支持 | 支持 |
